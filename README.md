# Leto 投资书籍合集

Leto 推荐的投资经典书籍在线阅读网站。

## 在线访问

https://leto.fate.red

## 收录书籍

1. **生命周期投资法** — 伊恩·艾尔斯、巴里·纳莱巴夫
2. **持续买入** — 尼克·马吉奥利
3. **彼得·林奇投资经典全集** — 彼得·林奇
4. **期权投资策略** — 劳伦斯·G·麦克米伦
5. **The Second Leg Down** — Hari P. Krishnan

## 技术栈

- [VitePress](https://vitepress.dev/) — 静态站点生成器
- [Cloudflare Pages](https://pages.cloudflare.com/) — 部署平台
- 自托管 Noto Serif SC 中文字体

## 本地开发

```bash
cd site
pnpm install
pnpm dev
```

## 构建

```bash
cd site
pnpm build
```

## 部署

推送到 `main` 分支自动部署到 Cloudflare Pages。
