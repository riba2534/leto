# 生命周期投资法

让你退休无忧的理财智慧

基于生命周期理论的投资策略，教你如何在不同年龄段合理配置资产，实现退休无忧。核心思想：分散时间投资，年轻时利用杠杆增加股票敞口，年老时逐步降低风险。
